# BLOOM 심미치과 샘플 사이트

정적 HTML이라 빌드가 필요 없습니다. `index.html`(목차)이나 `main.html`을 열면 됩니다.

- `assets/bloom.css`, `assets/bloom.js`: 모든 페이지에 공통으로 붙는 레이어(모바일 메뉴, 빠른 예약 바, 예약 신청 창, FAQ, 의료광고 고지)
- `img/`: 원본 단일 파일에 들어 있던 이미지를 분리해 webp로 바꾼 것

## 실제 납품 전에 바꿔야 할 것

- 병원명, 대표자, 사업자번호, 주소, 전화번호(`02-000-0000`), 카카오톡 채널·네이버 예약 링크
- `info.html`의 비급여 진료비용 실제 금액, 개인정보 보호책임자
- 예약 폼: `assets/bloom.js` 맨 위 `ENDPOINT`에 접수 서버 URL 입력 (비어 있으면 데모 접수 메시지만 표시). 네이버 예약·카카오톡 링크도 같은 곳에 있음
- 원장·팀 사진, 치료 사례 사진: AI 샘플 이미지 → 실제 사진(환자 동의 필수)
- 같은 내용을 광고·블로그·SNS에 쓸 때는 의료광고 심의를 따로 받아야 함
