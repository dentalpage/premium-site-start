# BLOOM 심미치과 — 프로젝트 규칙

이 폴더는 BLOOM 심미치과 홈페이지 작업 공간이다.

- 작업 전에 반드시 `PLAN.md`(기획안 v2)를 먼저 읽는다. 메뉴 구조, 페이지별 섹션, 카피는 기획안을 따른다.
- 루트 CLAUDE.md의 치과 규칙과 기획안이 다르면 **기획안이 우선**한다. 단, 컬러는 아래 "톤 & 컬러: 어두운 톤"을 따른다.
- 기획안의 카피는 샘플이다. "26. 추후 실데이터 확인 항목"에 있는 내용(가격, 이력, 장비, B&A 등)은 지어내지 않고 플레이스홀더로 둔다.

## 톤 & 컬러: 어두운 톤 (확정)

- BLOOM은 **어두운 톤**으로 간다. 기획안 "25. 디자인 방향"의 `White 80~90%` 비율은 적용하지 않는다.
- 기본 색은 루트 치과 규칙의 **톤 A 컬러 토큰**(검정·베이지·토프·하이라이트)을 쓴다. 톤 B 패턴에 쓸 어두운 면 색만 아래 토큰으로 추가한다.

```css
:root {
  --b-graphite: #1C1C1E; /* 톤 B 패턴을 어둡게 쓸 때의 면·카드 배경 */
  --b-line:     #2E2E2E; /* 어두운 배경 위 얇은 구분선 */
}
```

- 섹션 배경은 검정 → 그라파이트 → (호흡용) 베이지 순으로 교차한다. 흰 배경 섹션은 페이지당 1개 이하.
- 기획안의 "얇은 라인, 큰 이미지, 작은 캡션, 큰 헤드라인, 좌텍스트/우이미지 반복 금지"는 그대로 따른다.

## 메인페이지: 톤 A 기본 + 톤 B 레이아웃 혼합

- 분위기와 색은 톤 A, 정보가 필요한 구간은 톤 B 레이아웃을 가져와 **어두운 색으로 바꿔** 쓴다(흰 바탕 → `--a-black`/`--b-graphite`, 딥그린 → `--a-white`/`--a-beige`, 골드 → `--a-text-sub`).
- 기획안 "9. 메인페이지" 순서에 패턴을 다음처럼 대응한다.

| 1 | Hero | 영상 | 삶의 장면 영상 + 좌하단 대형 장면 문장 + "다시, 피어나다." |

## 규칙 완화 (사용자 승인, 레퍼런스 반영)

BLOOM에서는 아래 항목이 루트 치과 규칙보다 우선한다.

- **히어로는 "삶의 장면"으로 만든다.** 치료 후의 일상 장면 영상(예: 친구 결혼식 단체사진) 위에, 타깃이 공감할 장면 문장을 크게 올리고 브랜드 문장("다시, 피어나다.")은 그 아래에 둔다. 결과를 보장하는 문장("~할 수 있습니다")은 쓰지 않고, 공감형 조건문("~했다면")으로 쓴다.
- **섹션 리듬을 크게 바꾼다.** 풀스크린 어둠 → 베이지 반반 → 풀블리드 사진 위 텍스트 → 밝은 에디토리얼 → 토프 인용처럼 섹션마다 배경·밀도·정렬을 다르게 한다. 같은 레이아웃을 연달아 쓰지 않는다.
- 밝은 섹션(`#F5F3EF`)은 페이지당 2개까지 허용한다.
- 튀는 요소 1곳 제한, 히어로 카피 44px 제한은 풀어준다(히어로 카피 데스크톱 56~64px).
- 모션: 주요 블록에 한 번만 재생되는 스크롤 페이드인(24px 이하, 0.8s)을 허용한다. `prefers-reduced-motion`이면 끈다.
- 레퍼런스 사이트의 병원명·카피·사진·구성은 그대로 가져오지 않는다. 가져오는 것은 위 두 가지 원리뿐이다.
