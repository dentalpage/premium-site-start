# BLOOM 심미치과 — 프로젝트 규칙

이 폴더는 BLOOM 심미치과 홈페이지 작업 공간이다.

- 작업 전에 반드시 `PLAN.md`(기획안 v2)를 먼저 읽는다. 메뉴 구조, 페이지별 섹션, 카피는 기획안을 따른다.
- 루트 CLAUDE.md의 치과 규칙과 기획안이 다르면 **기획안이 우선**한다. 특히 컬러·레이아웃은 기획안 "25. 디자인 방향"을 따른다(White 80~90%, Light Gray, Graphite, 필요 시 Muted Rose / Rust 최소 사용).
- 기획안의 카피는 샘플이다. "26. 추후 실데이터 확인 항목"에 있는 내용(가격, 이력, 장비, B&A 등)은 지어내지 않고 플레이스홀더로 둔다.

## 톤 & 컬러: 어두운 톤 (확정)

- BLOOM은 **어두운 톤**으로 간다. 기획안 "25. 디자인 방향"의 `White 80~90%` 비율은 적용하지 않는다.
- 기본 색은 루트 치과 규칙의 **톤 A 컬러 토큰**(검정·베이지·토프·하이라이트)을 쓴다. 톤 B 패턴에 쓸 어두운 면 색만 아래 토큰으로 추가한다.

```css
:root {
  --b-graphite: #1C1C1E; /* 톤 B 패턴을 어둡게 쓸 때의 면·카드 배경 */
  --b-line:     #2E2E2E; /* 어두운 배경 위 얇은 구분선 */
}
```

- 섹션 배경은 검정 → 그라파이트 → (호흡용) 베이지 순으로 교차한다. 흰 배경 섹션은 페이지당 1개 이하.
- 기획안의 "얇은 라인, 큰 이미지, 작은 캡션, 큰 헤드라인, 좌텍스트/우이미지 반복 금지"는 그대로 따른다.

## 메인페이지: 톤 A 기본 + 톤 B 레이아웃 혼합

- 분위기와 색은 톤 A, 정보가 필요한 구간은 톤 B 레이아웃을 가져와 **어두운 색으로 바꿔** 쓴다(흰 바탕 → `--a-black`/`--b-graphite`, 딥그린 → `--a-white`/`--a-beige`, 골드 → `--a-text-sub`).
- 기획안 "9. 메인페이지" 순서에 패턴을 다음처럼 대응한다.

| 순서 | 기획안 섹션 | 패턴 |
|---|---|---|
| 1 | Hero | A-HERO (카피는 기획안 Hero **A안** "다시, 피어나다.") |
| 2 | Brand Principle | A-STATEMENT |
| 3 | Treatment Category | B-SPLIT-HALF ×3 (좌우 번갈아 배치) |
| 4 | BLOOM TEAM | B-TEAM 응용 3열(원장·기공사·치과위생사) |
| 5 | Before & After Preview | B-RESULT |
| 6 | Journal Preview | A-GALLERY |
| 7 | General Care | B-SPLIT |
| 8 | Visit / CTA | B-MAP + A-CLOSING |
| 9 | Footer | 톤 A 푸터 |

- "튀는 요소는 페이지당 1곳" 원칙에 따라 메인의 튀는 요소는 A-HERO 풀스크린 영상 하나로 한다.
