# 모두의치과 샘플 — 다음 작업

## 수정할 것
1. **모바일 버벅임** — 휴대폰 전용 가벼운 프레임(작은 해상도·적은 장수) 만들기. 크레딧 0.
2. **의료법 점검** — 다른 치과를 비방하는 것처럼 읽힐 수 있는 문구 고치기.
   - 1번 장면 "붙잡고 울리는 치료 대신…"
   - 우리의 약속 "억지로 붙잡지 않아요"
   - FAQ "억지로 붙잡고 진행하지 않아요"
   - 그 밖에 비교·최상급·보장 표현 전체 점검
3. **첫 방문 메시지** — "첫날은 치료하지 않아요"가 급한 부모(통증·충치)에게 막히지 않게
   (예: 급할 땐 당일 진료 가능 + 아이가 준비되는 만큼 진행) — 실제 운영 방식 확인 필요.
4. **보호자 동행 장면** — 필요하면 문구/장면 수정. 영상 재생성은 크레딧 사용(장면 1개 ≈ 10).
