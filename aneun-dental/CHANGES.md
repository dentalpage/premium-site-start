# 레이아웃 점검 및 수정 내역

기존 디자인(색상, 폰트, 이미지, 문구)은 그대로 두고 간격, 카드 정렬, 반응형만 손봤습니다.

- CSS 수정은 모두 새 파일 `layout-fixes.css`에 모았습니다. 이 파일은 `mobile.css` 다음에 마지막으로 불러옵니다. 기존 CSS 파일은 건드리지 않았습니다.
- `index.html`은 아래 세 가지만 바꿨습니다.
  - `layout-fixes.css` 링크 추가
  - 모바일에서 숨겨지는 `<br>` 앞에 공백 추가
  - 이미지 SVG 9개에 `preserveAspectRatio` 추가
- 점검 화면 폭: 1440 / 1024 / 768 / 390 / 360px (Playwright로 측정)

| 1 | 원장소개 | 768px | 원장 사진이 화면 밖으로 5px 튀어나가 **가로 스크롤 발생** (문서 폭 773px) | `.doctor{overflow-x:clip}` 적용, 가로 스크롤 없음 (1440px에서 생기던 1px 넘침도 함께 해결) |

| 8 | 임플란트 사후관리 목록 | 701~1000px | 4칸이 너무 좁아 "정기 / 검진", "주변 / 위생관리"처럼 단어가 줄바꿈됨 | 2×2 배치 |

## 확인 결과

- 1440/1024/768/390/360px 모두 문서 폭이 화면 폭과 같아서 가로 스크롤이 없습니다 (수정 전: 768px에서 773, 1440px에서 1441).
- 1024px에서는 통증케어 섹션이 기존 겹침 배치를 그대로 유지합니다. 7번 수정은 900px 이하에만 적용됩니다.

## 식스샵에 옮길 때

이 사이트는 아직 식스샵에 올라가 있지 않습니다. 식스샵 `dental1` 스토어에는 다른 사이트("스마일 아키텍트 교정치과")가 있습니다. 식스샵 코드 블록으로 옮길 때 `layout-fixes.css` 내용을 마지막 스타일로 함께 넣어 주세요.
