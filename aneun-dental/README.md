# 아는치과 홈페이지 코드

PC·모바일 반응형 홈페이지의 HTML, CSS, JavaScript와 이미지가 포함되어 있습니다.

## 실행
압축을 풀고 index.html을 브라우저에서 열면 됩니다. 또는 폴더에서 python -m http.server 8000 을 실행하고 http://localhost:8000 으로 접속하세요.

## 수정
index.html: 내용과 섹션 구조
app.js: 메뉴, 증상 탭, 예약 안내
mobile.css: 모바일 전용 레이아웃
나머지 CSS: 공통 스타일 및 섹션별 스타일
assets/: 사진과 이미지

CSS는 index.html에 선언된 순서대로 적용됩니다. 모바일 수정 이력이 mobile.css에 누적되어 있으며 뒤쪽 규칙이 우선합니다.
Google Fonts는 인터넷 연결이 필요합니다. 예약 버튼은 실제 예약 연결이 아닌 샘플 안내입니다. 의료진, 병원 정보와 진료 이미지는 판매 샘플용입니다.

식스샵에 적용하려면 해당 플랫폼의 코드 블록 구조에 맞추고 이미지 경로를 업로드 주소로 변경해야 합니다.
