# 식스샵 적용 (anundental 스토어)

`aneun-dental` 수정본을 식스샵 커스텀 블록 10개로 옮긴 소스입니다.

- **스토어:** `anundental` (`anundental.sixshop.site`)
- **테마:** Essential, **아직 게시 전**
- 블록 소스는 `blocks/*.block.html`, 블록 설정은 `blocks/*.settings.json`, 스토어에 등록된 블록 ID는 `block-ids.txt`에 있습니다.

## 스토어에 반영한 내용

| 위치 | 섹션 이름 | 블록 |
|---|---|---|
| 상단 (전체 페이지 공통) | 아는치과 헤더 | 아는치과 · 헤더 메뉴 |
| 홈 (페이지 이름: 새 페이지 1) | 메인 배너 / 진료 약속 / 원장소개 / 첫방문 / 통증케어 / 증상별 진료 / 임플란트 / 오시는 길 | 섹션마다 같은 이름의 블록 1개 |
| 하단 (전체 페이지 공통) | 아는치과 푸터 | 아는치과 · 푸터와 예약 안내 (모바일 하단 고정 예약 버튼, 예약·안내 팝업 포함) |

- 새로 만든 섹션은 모두 전체 폭이고 여백은 0입니다.
- 원래 있던 헤더 섹션(히어로 배너 포함)과 푸터 섹션은 **지우지 않고 숨김 처리**만 했습니다. 에디터에서 해당 섹션의 표시를 다시 켜면 그대로 돌아옵니다.
- 테마 맞춤 코드(head)에 Noto Serif KR과 Noto Sans KR의 400/500/600 굵기를 불러오는 링크를 넣었습니다.

## 에디터에서 해야 할 일

| 블록 | 이미지 파일 |
|---|---|
| 메인 배너 | hero.webp |
| 원장소개 | doctor.webp, doctor-reference.webp |
| 첫방문 안내 | first-visit-identity.webp, exam-panorama-v2.webp, exam-ct-v2.webp, exam-pa-v2.webp, exam-oral-v2.webp, exam-qray-v2.webp, first-visit.webp, scaling-insurance.webp |

### 2. 미리보기에서 확인할 것

- **헤더 고정:** "아는치과 헤더" 섹션의 고정 값을 `top`으로 설정했어요. (`sticky`는 식스샵이 인식하지 않는 값이었어요.)
- **블록 너비:** 블록이 화면 폭 전체를 채우는지 확인하세요. 가운데로 좁아지면 섹션의 레이아웃 정렬을 "늘이기(꽉 채움)"로 바꿔 주세요.
- **페이지 이름:** 필요하면 "새 페이지 1"을 "홈" 등으로 바꿔 주세요.

## 상담 버튼·예약 신청서 (푸터 블록)

- 화면 오른쪽 아래에 **카카오톡 상담**, **네이버 톡톡**, **상담하기** 버튼이 위에서부터 차례로 고정돼요. 모든 페이지에 보여요. 모바일에서는 카카오톡·톡톡이 동그란 아이콘으로 줄어들어요.
- **상담하기**를 누르면 위의 두 채널 버튼을 접거나 펼쳐요. 처음에는 펼쳐져 있어요.
- 첫 화면(메인 배너)에서는 숨어 있다가, 두 번째 섹션이 보이기 시작하면 나타나요.
- 식스샵 하단 "식스샵 프로로 제작" 띠가 있으면 그 위로 자동으로 올라가요.
- 식스샵은 화면에 들어오기 전 블록을 숨기기 때문에(`visibility:hidden`), 고정 버튼과 예약 신청서는 CSS에서 직접 `visibility:visible`로 보이게 했어요. 이걸 빼면 푸터까지 내려가야 버튼이 보여요.
- 채널 링크는 푸터 블록 설정의 "카카오톡 상담 링크", "네이버 톡톡 링크"에 넣어 주세요. 비어 있으면 버튼을 눌렀을 때 "준비 중" 안내가 떠요. 카카오 링크가 비어 있으면 테마 SNS 설정의 카카오 주소를 대신 써요.
- **헤더 메뉴**는 "아는치과 헤더" 섹션의 "스크롤 시 섹션 고정"을 위(`top`)로 설정해 스크롤해도 위에 붙어 있어요.
- 예약 신청서는 고정 버튼에서 뺐어요. 헤더의 **예약하기**, 푸터의 "네이버 예약" 등 페이지 안의 예약 버튼을 누르면 열려요.
  - 받는 항목: 이름, 연락처(필수), 이메일, 상담 받고 싶은 진료, 희망 날짜, 희망 시간대, 궁금한 점, 개인정보 동의(필수)
  - 신청 내용은 **"상담 예약 접수" 게시판**(주소 `/boards/consult-request`)에 쌓여요. 운영자만 읽을 수 있고, 검색엔진에 노출되지 않아요. 새 글이 오면 스토어 알림이 가요.
  - 이메일 칸은 테마 SNS 설정에 이메일이 있으면 선택, 없으면 필수예요. (비회원 글쓰기에 이메일이 필요해서예요.)
- 개인정보 보유 기간("상담 완료 후 1년")은 예시 문구예요. 병원 개인정보처리방침에 맞게 고쳐 주세요.
- `tools/consult-test.js`로 상담·예약 흐름을 브라우저에서 확인할 수 있어요. (실제 게시판 저장은 흉내만 내요.)

## 홈페이지 진단 반영 (2026-10-31)

진단 리포트(72점)의 "개선 필요"·"보완" 항목 중 코드로 고칠 수 있는 것을 반영했어요.

| 진단 항목 | 고친 내용 |
|---|---|
| 속도 (모바일 약 9초) | 페이지 안에 통째로 들어 있던 사진 18장(약 5.4MB)을 이미지 서버(Cloudinary) 주소로 바꾸고, 자동 압축(`f_auto,q_auto`)을 켰어요. 홈페이지 HTML이 약 6.0MB → 0.7MB(전송 약 90KB)로 줄었어요. |
| 모바일 글자 크기 | 원장 약력, 검사 설명, 보험 스케일링 표, 진료시간을 모바일에서 13~14px로 키웠어요. |
| 예약·문의 연결 | 전화번호를 누르면 바로 전화가 걸려요(푸터·오시는 길·예약 신청서). 상담 버튼 묶음 맨 위에 "전화 상담" 버튼을 넣었어요. 푸터 블록 설정에 "네이버 예약 링크"를 넣으면 '네이버 예약'과 신청서 위 버튼이 네이버 예약으로 연결돼요. |
| 검색 노출 | 홈페이지 검색 설명 문구·키워드와 치과 구조화 데이터(Dentist, 진료시간)를 넣었어요. 오시는 길 블록 설정에 "네이버 플레이스 링크"를 넣으면 '네이버 지도에서 보기' 버튼이 생겨요. |

전화번호는 지금 샘플 값(000-0000-0000)이에요. 푸터 블록과 오시는 길 블록 설정의 전화번호를 실제 번호로 바꿔 주세요.

## 다시 만들기

`tools/` 폴더 스크립트를 이 순서로 실행하면 같은 블록이 다시 만들어집니다: `extract-blocks.js` → `build-blocks.js` → `minify.js` → `preview.js`.

- `preview.js`는 식스샵의 CSS 범위 지정과 기본 스타일 초기화를 흉내 낸 미리보기를 만듭니다.
- 이 미리보기로 원본 사이트와 비교한 결과, 1440 / 1024 / 768 / 390 / 360px 모두 페이지 높이가 같고 다른 픽셀은 33개 이하였습니다.
