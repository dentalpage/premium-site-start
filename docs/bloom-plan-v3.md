## 2. 사이트 설계 원칙

**핵심 진료는 명확하게**
✏️ 라미네이트와 심미레진을 ABOUT 바로 다음, GNB 앞쪽 핵심 카테고리로 배치한다.

**일반진료는 신뢰의 전이**
일반진료 자체로 환자를 대량 유입시키는 것이 목적이 아니다.
충치·잇몸·신경치료처럼 기본적인 치료에서도 원칙을 지키는 모습을 보여주어
"심미치료 역시 이 정도로 꼼꼼하게 하겠구나"
라는 신뢰가 자연스럽게 이어지게 한다.
콘텐츠 볼륨은 심미치료 페이지보다 작게 유지한다.

**ABOUT은 스토리부터**
원장 이력보다 BLOOM이 어떤 문제를 보고 어떤 원칙을 만들었는지를 먼저 보여준다.
순서: 철학 → 원장 → 팀 → 이력

**시술명은 실제 통용 명칭을 사용**
라미네이트, 심미레진, 치아미백, 잇몸미백 등 환자들이 실제로 알고 검색하는 명칭을 그대로 사용한다.
과도한 조어형 시술명은 사용하지 않는다.
BLOOM이라는 브랜드가 이미 감성적·에디토리얼 인상을 만들기 때문에 치료명까지 마케팅화하지 않는다.

## 3. 브랜드 컨셉

### Positioning Statement

BLOOM은 교정은 부담스럽지만 치아의 색과 형태를 자연스럽게 개선하고 싶은 20~30대 직장인과, 기존 심미치료를 다시 하고 싶은 환자에게 합리적인 가격으로 라미네이트·심미레진·미백을 제공하는 심미치과다.
필요 이상의 치아 삭제를 줄이고, 실제 치아를 직접 보고 색을 확인하며, 기존 보철물을 다시 치료하는 경우에는 남아 있는 치아와 잇몸 상태를 더욱 신중하게 확인한다.

### 타깃

- 20~30대 직장인
- 교정까지는 부담스럽지만 심미 개선을 원하는 사람
- 자연스러운 색과 형태를 원하는 사람
- 기존 라미네이트나 보철물 결과가 마음에 들지 않는 사람
- 과도한 치아 삭제를 걱정하는 사람
- 고가이거나 과장된 심미치과에 부담을 느끼는 사람 ✏️ **(내부 타깃 정의용. 웹 카피로 사용 금지, 타 기관 비교 광고 소지)**

### 가격 포지션

대중가 심미치과.
저가를 강조하지 않는다.
부담스럽지 않은 가격 + 충분히 좋은 결과 + 명확한 원칙을 포지셔닝한다.
✏️ 웹에서는 "할인", "이벤트가", "최저가" 등 가격 유인 표현을 쓰지 않는다.

## 4. BLOOM의 핵심 차별점

### 01. 삭제량에 대한 원칙

치아를 많이 깎는 것이 좋은 결과를 의미하지 않는다.
가능한 범위에서 자연치, 특히 법랑질을 최대한 보존한다.
단, 배열·변색·기존 보철 상태 등에 따라 필요한 삭제량은 달라질 수 있으며 이를 사전에 설명한다.

### 02. 직접 확인하는 색

사진 한 장만으로 치아 색을 결정하지 않는다.
✏️ 필요한 경우 원장과 기공사가 함께 실제 치아의 색과 특징을 확인하고, 그 결과를 제작에 반영한다.

### 03. 재제작에 대한 신중함

처음 치료하는 치아와 이미 한 번 치료받은 치아는 같은 상태가 아니다.
기존 라미네이트나 보철물을 제거한 뒤에는 남아 있는 치아의 양이 더 적을 수 있고, 잇몸 상태도 함께 확인해야 한다.
따라서 BLOOM은 재제작일수록
더 많이 손대는 것보다
어디까지 손대지 않아도 되는지를 먼저 본다.

### 04. TEAM

BLOOM의 핵심은 인원이 많다는 것이 아니다.
필요한 치료에 필요한 사람이 함께한다.
라미네이트에는 원장·기공사·치과위생사가 참여하고, 심미레진과 미백은 해당 치료에 실제로 필요한 구성원이 함께한다.
환자가 한 사람의 판단에만 의존한다는 느낌보다, 여러 역할의 사람이 함께 치료 과정을 관리한다는 안심을 전달한다.

## 6. Tone & Voice

**기본**
단정적이지만 공격적이지 않다.
전문적이지만 딱딱하지 않다.
존댓말을 사용하되 병원 안내문처럼 쓰지 않는다.

**피해야 할 것**

- 최고 / 완벽 / 무조건 / 절대 / 가장 / 100%
- 재발 없음, 무삭제 단정
- 치료 결과를 보장하는 표현
- ➕ "깎지 않는", "통증 없는", "부작용 없는" 등 단정 표현
- ➕ 타 의료기관의 치료 결과를 평가하거나 비교하는 표현
- ➕ "결과로 증명", "말보다 결과" 등 결과를 근거로 내세우는 표현

**지향하는 문장**

- 삭제는 꼭 필요한 만큼만 합니다.
- 사진 한 장으로 색을 정하지 않습니다.
- 다시 하는 치료일수록 조금 더 조심스럽게 봅니다.
- 필요한 사람이 함께 봅니다.

## 7. TEAM 구조

**Main Message**
예쁜 치아는 한 사람이 만드는 게 아닙니다.
BLOOM은 필요한 사람이 함께 만듭니다.

**원장 — 진단과 설계** ✏️
어디까지 치료할지, 어디에서 멈출지를 판단한다.

**기공사 — 색과 형태의 구현**

**치과위생사 — 치료 준비와 유지관리**

✏️ 개원 후 기존 라미네이트나 심미보철을 다시 하고 싶다며 찾아오는 분들을 자주 만났다.

- 삭제는 꼭 필요한 만큼만.

- 다시 하는 치료일수록 더 신중하게 볼 것.

BLOOM은 그 원칙에서 시작한다.

## 13. 라미네이트 제작 과정 ✏️ (전면 수정)

> v2에는 **치아 삭제(Preparation)와 임시치아 단계가 빠져 있었다.** "삭제는 필요한 만큼만"이 핵심 메시지인 브랜드에서 삭제 단계가 공정표에 없으면 오히려 숨기는 것처럼 보인다.

| 단계 | 내용 |
|---|---|
| 01 DIAGNOSIS 진단 | 현재 치아와 잇몸 상태, 기존 보철 여부를 확인하고 치료 가능 범위를 판단한다. |
| 02 SCAN 기록 | 현재 치아의 형태와 교합 상태를 기록한다. |
| 03 DESIGN 설계 | 가능한 경우 최종 형태를 사전에 계획하고 환자와 공유한다. ※ 실제 장비·프로세스 확인 후 확정 |
| 04 SHADE 색 확인 | 삭제 전 자연치 색을 기록하고, 필요한 경우 원장과 기공사가 함께 확인한다. |
| 05 PREPARATION 삭제 | 설계에 따라 필요한 범위만 다듬는다. 예상 범위는 사전에 설명한다. |
| 06 IMPRESSION 인상 | 다듬은 치아의 정보를 기공 과정으로 전달한다. |
| 07 TEMPORARY 임시치아 | 제작 기간 동안 임시치아를 사용한다. ※ 운영 방식 확인 |
| 08 DELIVERY 부착 | 형태·색·교합을 확인한 뒤 최종 부착한다. |
| 09 CARE 관리 | 치과위생사가 관리 방법을 안내하고 정기 점검 일정을 잡는다. |

- 큰 보철치료까지는 부담스러운 경우

### Signature Protocol

**원장의 원칙**
가능한 범위에서 자연치를 최대한 보존합니다.
치료 부위에 맞는 방습과 접착 과정을 거쳐 색과 형태를 단계적으로 완성합니다.

**위생사의 원칙**
치료 준비와 시술 보조, 치료 후 유지관리 안내까지 함께합니다.

1. 진단
2. ➕ 색 선택 (Shade)
3. 방습 및 준비
4. 적층
5. 형태와 색 조정
6. ➕ 교합 확인
7. 연마

※ 러버댐은 모든 증례에서 반드시 사용하는 경우에만 절대적 표현을 사용한다.

작은 차이가, 인상을 바꿉니다.
객관적 케이스 정보와 필수 고지(18장)를 함께 표시한다.

- 삭제 없이 인상 변화를 원하는 경우

### Principle

미백에 앞서 변색의 원인과 현재 치아 상태를 먼저 확인합니다.

**치과위생사**

|---|---|

| 02 준비 | 잇몸과 주변 조직을 보호하고 미백을 준비한다. |
| 03 미백 | 현재 치아 상태에 맞는 계획에 따라 진행한다. |
| 04 확인 | 밝기 변화와 치아·잇몸 상태를 확인한다. |
| 05 관리 | 착색과 민감도 관리 방법을 안내한다. |

- 기존 보철 여부
- 주요 개선 항목

**➕ 필수 준수 사항 (의료광고)**

- 모든 B&A 이미지에 부작용·개인차 고지 문구를 함께 표시한다.
- 전후 사진은 같은 조건(조명, 각도, 거리, 노출)으로 촬영한다.
- 색 보정, 리터칭, 합성을 하지 않는다.
- 환자의 서면 동의(게시 범위·기간 포함)를 받는다.
- 얼굴 전체 노출은 별도 동의가 있을 때만 사용하고, 기본은 구강 부위 크롭으로 한다.
- 게시 방식(전체 공개 또는 회원 열람 등)은 오픈 전 심의·자문 결과에 따라 확정한다.

## 21. 일반진료

일반진료의 목적은 심미치료 실력을 직접 홍보하는 것이 아니라, 치아를 대하는 기본 태도를 보여주는 것이다.

### Hero

심미는 기본 위에 올라갑니다.
충치와 잇몸이 건강해야
아름다운 치료도 오래 갈 수 있으니까요.

### Core Treatment

- **신경치료** — 가능한 경우 자연치를 오래 보존하는 방향을 먼저 고민합니다.
- **잇몸치료** — 보철을 시작하기 전에 잇몸 상태부터 확인합니다.
- **충치치료** — 다시 문제가 생길 위험을 줄일 수 있도록 접착과 마무리까지 꼼꼼하게 봅니다.

### Director's Voice

심미치료 상담으로 오셨어도
잇몸이나 충치 치료가 먼저 필요한 경우가 있습니다.
조금 돌아가는 것처럼 느껴질 수 있지만
오래 사용하려면 기본이 먼저입니다.

  - 예: 치료 범위와 기존 보철물의 상태에 따라 비용은 달라질 수 있습니다. 상담 후 예상 비용을 먼저 안내해 드립니다.
