# 쉼표치과: 기획 피드백과 페이지 구성

입력: **"치과가 무서워서 치료를 못하는 환자들을 위한 치과"**

---

## 1. 피드백 (2번 자료 billion-dollar-board 프레임워크 적용)

### Seth Godin: 타깃이 아직 넓습니다 (SVM)
"치과가 무서운 환자"에는 아이, 노인, 임플란트를 고민하는 사람, 단순 스케일링 환자가 모두 섞여 있습니다. 한 사람으로 좁혔습니다.

> **치과가 무서워 몇 년째 미뤄 왔고, 이제 이가 아프기 시작한 30~40대 성인**

이 사람의 브랜드 스토리 5요소는 다음과 같습니다.
| 요소 | 내용 |
|---|---|
| 현재 상태 | 이가 시큰거리지만 예약 버튼 앞에서 매번 멈춘다 |
| 외부 문제 | 드릴 소리, 마취 주사, 갑자기 시작되는 치료 |
| 내부 문제 | "왜 이렇게 될 때까지 놔뒀냐"는 말을 들을까 봐 부끄럽다. 입을 벌린 채 아무것도 통제할 수 없는 무력감 |
| 철학적 문제 | 무서운 게 죄가 아닌데, 치과는 무서워하는 사람을 기준으로 설계돼 있지 않다 |
| 변화 | 내가 정한 속도로, 혼나지 않고, 언제든 멈출 수 있는 치료 |

### Godin, Purple Cow: "무통·친절 치과"는 보이지 않습니다
모든 치과가 하는 말이라 기억에 남지 않습니다. 말할 거리가 되는 **하나의 메커니즘**으로 바꿨습니다.
→ **"손 들면, 바로 멈춥니다."** 공포의 핵심인 *통제 상실*을 정면으로 해결합니다.

### Alex Hormozi, 가치 방정식: 노력과 리스크를 0에 가깝게
- 달성 가능성: 단계마다 미리 설명하고, 비용도 치료 전에 전부 안내
- 시간 지연과 노력: **첫 방문은 치료 없이 상담만** (가장 무서운 "그날 바로 치료"를 제거)
- 결과적으로 CTA는 "치료 예약"이 아니라 **"치료 없이 상담만 예약하기"**. 진입 장벽이 가장 낮은 한 걸음입니다.

### Tony Robbins, 6가지 욕구: 확실성을 1순위로
이 고객이 사는 것은 '치료'보다 **확실성(예측 가능함)과 존중**입니다. 그래서 모든 장면의 카피가 "미리 알려줌, 내가 결정함"을 반복합니다.

### Dan Kennedy, 메시지-마켓 매치와 국내 의료광고 주의
- 공포 고객에게는 혜택 나열보다 **공감 한 문장**이 먼저입니다. 그래서 첫 문장을 "무서워서 미룬 거, 다 알아요."로 정했습니다.
- 의료법상 **치료 후기, 전후 사진, "100% 무통" 같은 절대 표현은 쓰지 않았습니다.** "줄였어요", "상의해요" 같은 표현만 사용하고 하단에 고지 문구를 넣었습니다. 실제 오픈 전에는 의료광고 사전심의를 받으세요.

### 실제 정보로 바꿔야 할 것 (가정한 부분)
- 병원 이름 **'쉼표치과'**는 제안한 이름입니다. ("잠시 멈춤 = 손 들면 멈춤"의 상징)
- 노이즈캔슬링 헤드폰, 전동 마취기, 진정치료, 30분 상담은 **실제로 제공하는 것만** 남기세요.
- 예약 링크는 `index.html`의 `BOOKING_URL`을 바꾸면 됩니다.

## 2. 양식에 맞춘 재구성

- **브랜드:** 쉼표치과. 무서워서 미룬 사람을 위한 치과
- **무드:** 애플 공홈처럼 미니멀하고 밝은 웜 오프화이트 배경(#F4F1EC), 포인트 색은 진정을 주는 틸 그린(#2F9E8F) 하나. 부드러운 클레이 미니어처 아이소메트릭 세계
- **장면 1 · 문 앞:** 치과 건물 앞에서 머뭇거리는 환자 ("…" 말풍선)
  → *무서워서 미룬 거, 다 알아요.*
- **장면 2 · 첫 상담:** 소파와 차 두 잔, 마주 앉은 상담실
  → *첫날은 이야기만 합니다.* (치료 없는 첫 방문, 비용 사전 안내, "왜 이제 왔어요" 금지)
- **장면 3 · 진료실:** 헤드폰을 쓰고 누운 환자, 벽에는 자연 영상
  → *드릴 소리도, 따끔함도 줄였어요.*
- **장면 4 · 멈춤 신호:** 손을 들자 일시정지 신호가 뜨고 의사가 한 걸음 물러섬
  → *손 들면, 바로 멈춥니다.*
- **장면 5 · 다시 웃는 날:** 햇살 드는 정원 벤치에서 웃는 환자
  → *미뤄온 그 이, 이번엔 천천히.*
- **마지막:** **[치료 없이 상담만 예약하기]** 버튼 하나 (상단 바에도 다른 CTA를 두지 않음)

## 3. 1번 자료(scroll-world) 적용 방식

scroll-world의 **스크롤 스크럽 엔진(`scrub-engine.js`, MIT)을 그대로** 사용합니다. 스크롤하면 카메라가 각 장면 안으로 들어갔다가 끊김 없이 다음 장면으로 날아갑니다.

원본은 장면 영상을 유료 AI 서비스(Higgsfield/Monid)로 생성합니다. 이 프로젝트는 같은 구조(장면 5개 + 다이브 영상 5개 + 연결 영상 4개)를 **코드로 그린 SVG 미니어처 세계를 카메라로 촬영하는 방식**으로 렌더링했습니다. 비용이 들지 않고, 하나의 세계를 하나의 카메라 경로로 찍기 때문에 이음매가 프레임 단위로 정확히 일치합니다. 모바일은 9:16 세로 체인을 따로 렌더링했습니다.

나중에 AI 영상으로 바꾸고 싶으면 `assets/vid/*.mp4`만 같은 이름으로 교체하면 됩니다.

## 실행 방법

```bash
cd dental-fear
python3 -m http.server 8000      # → http://localhost:8000

# 장면을 수정하고 다시 렌더링할 때 (Node + Playwright + ffmpeg 필요)
node tools/render.cjs /tmp/frames both
./tools/encode.sh /tmp/frames assets
```
